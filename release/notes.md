# v3.12.1-plugin.4

基于上游 v3.12.1 的 kumu-ze fork 实验插件系统。

## 对话页面自动连接

对话测试插件升级至 0.2.0，自动使用当前站点地址、读取已启用的 API Key。唯一 Key 默认选中，多个时下拉选择，省去手动粘贴和端口配置。

新增 ui.chat 页面能力。宿主管理页代发正常模型/Responses 请求，Key 明文仅在宿主页面内存中用于请求，不传入插件 iframe 或原生进程。保留同源限制、重定向拒绝、权限检查、并发/超时/大小上限和页面离开取消。

## 兼容与边界

新对话插件需要本宿主版本；旧插件继续可用。ui.chat 允许使用已有 Key 发起有用量的请求，须信任插件来源；没有逐 Key 安装授权或 OS 沙箱。详情与验证范围见 docs/plugins.md、docs/plugins-validation.md。
