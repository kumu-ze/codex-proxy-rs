# v3.12.1-plugin.3

基于上游 v3.12.1 的 kumu-ze fork 实验插件系统，供上游设计讨论与隔离验证使用。

## 下载诊断与代理

插件安装弹窗可选择宿主已保存的代理下载包，代理凭据由宿主解析。连接失败/超时、HTTP 错误、SHA256 不匹配和包格式错误分别提示，便于区分网络故障与无效安装包。

## 对话测试

新增独立示例插件 examples/plugins/chat。页面可填写 RS API Key、加载模型、进行多轮对话、查看逐步回复、停止请求，以及查看 HTTP 状态、请求 ID、耗时与用量。请求经过宿主标准 Responses 链路，方便验证路由和打标插件。密钥不写入插件数据文件。

## 限制

原生插件仍不是 OS 沙箱；下载代理参与最终目的地解析，应只选择可信代理。对话测试需要有效的 RS Key 与可用账号，会计入正常用量；模拟测试不代表完成真实生产账号验收。开发合同与风险见 docs/plugins.md，验证范围见 docs/plugins-validation.md。
