# v3.12.1-plugin.5

基于上游 v3.12.1 的 kumu-ze fork 实验插件系统。

## 对话参考插件

对话测试插件升级至 0.2.1，明确显示包含 `/v1` 的 API 地址。实际请求仍为同源 `/v1/models` 和 `/v1/responses`，不会重复拼接 `/v1`。参考插件索引、源码、权限合同、公开安装包和验证入口已整理，供未来上游 PR 引用。

## 验证实例目录恢复

验证实例的账号使用日本 SOCKS5 代理时，本地 DNS 解析导致目录连接超时；保留同一代理主机与端口，改用 SOCKS5H 由代理解析后，目录缓存已恢复，标准和 Codex 模型接口均实际返回 7 个模型。此项是验证实例配置修复，不改变其他部署的代理或 DNS 默认值。没有修改生产实例、凭据或模型权限。

诊断时使用过独立的临时目录查询进程；临时诊断代码已移除，生产目录超时预算未改。详情见 docs/plugins-validation.md。
