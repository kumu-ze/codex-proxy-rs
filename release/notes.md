# v3.12.1-plugin.2

本版本为 kumu-ze fork 的实验性插件系统，基于上游 v3.12.1（01006380），用于向上游提供可运行的设计参考；不是上游正式发行版。

## 插件管理

- 管理员可在插件页面通过 HTTP/HTTPS URL 下载 tar.gz 插件包，支持可选的整包 SHA256 校验；安装后默认停用。
- 提供启用、停用、失败后重新启动及卸载操作，无需重启 RS。卸载保留业务数据，运行状态保存到宿主运行目录。
- 插件声明 menuLabel 后，启用时在侧栏原生导航中显示独立入口；页面仍通过隔离 iframe 与受限调用桥运行。

## 框架与业务边界

继承 plugin.1 的外部进程通信、OpenAI 请求扩展和 Provider 服务桥。Turn-State 业务独立于宿主，宿主不内置打票调度、策略和业务页面。

## 升级与限制

首次启动导入 YAML plugins 配置，此后以运行目录 plugins/registry.json 为准，修改 YAML 不再覆盖界面状态。备份运行目录与插件数据后再升级；不得以官方主线二进制覆盖带历史 fork 迁移的数据库。

原生插件不是操作系统沙箱；只运行可信程序。暂无签名验证、自动更新、细粒度授权和数据库操作审计。完整接口、信任边界、回滚步骤及实际验证范围见 [插件文档](../docs/plugins.md) 与 [验证记录](../docs/plugins-validation.md)。
